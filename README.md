# DeathMessages

Death, join, and quit message formatting plugin

## » About

Applies custom MiniMessage colors to death, join, and quit messages. Supports separate colors for message text, players, killers, and weapons, along with weapon hover tooltips.

Players can control which messages they see and blacklist individual players from their death messages.

## » Commands

* `/deathmessages reload` — Reloads configuration and user data
* `/deathmessages toggle` — Toggles death messages
* `/deathmessages blacklist <player>` — Adds or removes a player from your blacklist
* `/toggleconnectionmsg` — Toggles join and quit messages
* `/deathmessagestoggle` — Shortcut for toggling death messages

## » Permissions

* `deathmessages.command.reload` — Reload configuration
* `deathmessages.command.toggle` — Toggle death messages
* `deathmessages.command.blacklist` — Manage your blacklist
* `deathmessages.command.toggleconnectionmsg` — Toggle join and quit messages

## » Configuration

Player preferences are stored in `UserData.yml`, which is created automatically when needed.

## » Compatibility

* Paper
* Folia

Enjoy DeathMessages!
